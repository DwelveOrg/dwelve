# Security Policy

This repository is a public marketing site and contains no authentication,
session, or product-data store. Its security architecture and invariants are
documented in [`docs/security/SECURITY.md`](docs/security/SECURITY.md).

No private vulnerability-reporting address or response SLA is defined in this
repository. Until maintainers publish one, disclose suspected vulnerabilities
privately to the repository owners and do not include exploit details, user
data, or credentials in a public issue.
